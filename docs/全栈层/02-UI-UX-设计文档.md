# AI 视频剪辑智能体 — 全栈层 UI/UX 设计文档

> 版本：v1.0 · 日期：2026-10-23
> 上游依据：PRD v1.0 · API 接口设计文档 v1.0
> 视觉基调：**Apple 极简风** —— 白底、#007AFF 主色、细边分层、无阴影

---

## 1. 设计原则

1. **manifest 驱动**：一切参数表单由 `GET /manifest` 动态渲染，核心库新增操作前端零改动
2. **状态先行**：任务六态（pending/running/success/failed/cancelled/timeout）在 UI 上有统一视觉语言
3. **Apple 极简风**：白底 + 细边框分层，**明确不采用**深色科技风、不使用阴影（用户明确反对）
4. 轮询友好：渲染为异步任务，UI 以任务卡为中心组织信息

## 2. 设计规范（Design Tokens）

### 2.1 颜色

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#FFFFFF` | 页面背景 |
| `--bg-sub` | `#F5F5F7` | 分区/次级背景 |
| `--primary` | `#007AFF` | 主按钮、进度条、运行中状态 |
| `--text` | `#1D1D1F` | 主文字 |
| `--text-2` | `#86868B` | 次级文字、说明 |
| `--border` | `#D2D2D7` | 1px 细边框（卡片、输入框） |
| `--success` | `#34C759` | success 态 |
| `--danger` | `#FF3B30` | failed 态、危险操作 |
| `--warning` | `#FF9500` | pending 态 |
| `--muted` | `#8E8E93` | cancelled/timeout 态 |

### 2.2 形状与字体

- 卡片圆角 **12px**；按钮圆角 **8px**；输入框圆角 8px
- 全部组件**无边框阴影**，靠 `1px solid var(--border)` 分层
- 字体：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- 主标题 20px/600，正文 14px/400，说明 12px/400

### 2.3 任务状态徽章规范

| 状态 | 徽章底色（10% 透明） | 文字色 | 图标 |
|---|---|---|---|
| pending | `#FF9500` 10% | `#FF9500` | ⏳ |

## 3. 页面结构

### 3.1 阶段 1：最小预览页（单页，无路由）

```
┌─────────────────────────────────────────────┐
│  AI 视频剪辑智能体 · 渲染控制台            │ ← 顶栏 44px，白底细底边
├──────────────────────┬──────────────────────┤
│ ① 提交区            │ ② 任务查询区         │
│  timeline JSON       │  task_id 输入框      │
│  textarea(等宽字体)  │  [查询] 按钮         │
│  options (折叠)      │  ───────────────     │
│  webhook_url (折叠)  │  ③ 任务状态卡        │
│  [提交渲染] 主按钮   │  状态徽章+进度条     │
│                      │  error_msg(失败时)   │
│                      │  [取消] [下载成片]   │
└──────────────────────┴──────────────────────┘
```

**组件说明**：
- ① 提交区：默认预填第十节最小 timeline 示例；非法 JSON 前端即时提示（红字，不阻塞输入）
- ② 查询区：粘贴 task_id 查询；查询成功后进入 ③
- ③ 任务状态卡：徽章 + 进度条（progress×100%）；按状态显隐按钮——pending/running 显示 [取消]，success 显示 [下载成片]，failed/timeout 显示 error_msg

### 3.2 阶段 2：时间轴编辑器（路由化）

```
┌───────────────────────────────────────────────────┐
│ 顶栏：项目名 | [撤销] [重做] | [导出渲染]         │
├──────────┬────────────────────────┬───────────────┤
│ 素材库   │  预览画布              │ 属性面板      │
│ (列表)   │  (当前帧/播放)         │ (manifest    │
│          ├────────────────────────┤  驱动表单)    │
│ [+导入]  │  时间轴轨道区          │               │
│          │  v_main ──▮▮▮──       │               │
│          │  a_main ──▮▮▮──       │               │
│          │  (拖拽/裁剪/转场)     │               │
└──────────┴────────────────────────┴───────────────┘
```

导出渲染 = 将编辑器状态序列化为 timeline JSON → POST /render → 弹出任务进度浮层（复用阶段 1 状态卡组件）。

## 4. 交互流程

### 4.1 提交 → 轮询 → 下载（核心链路）

```
用户编辑/粘贴 timeline
   │ [提交渲染]
   ▼
POST /render ── 202 {task_id, state:"pending"}
   │ 记录 task_id，前端每 2s 轮询 GET /render/{id}
   ▼
┌─ state=pending/running ─→ 更新进度条，继续轮询
├─ state=success ─────────→ 显示 [下载成片] → GET /render/{id}/download
├─ state=failed/timeout ──→ 红字展示 error_msg + [重新提交]
└─ state=cancelled ───────→ 灰色徽章 + [重新提交]
```

**轮询规则**：间隔 2s；连续 5 次网络错误提示「服务不可达」并停止轮询；用户离开页面停止轮询。

### 4.2 取消流程

```
[取消] 点击 → 二次确认弹窗（"确定取消该任务？此操作不可恢复"）
   → POST /render/{id}/cancel → 更新状态徽章
   → 若任务恰在间隙已完成（success），UI 以服务端返回状态为准（幂等设计）
```

### 4.3 manifest → 动态表单映射（阶段 2）

| manifest 字段 | 控件 |
|---|---|
| enum 枚举 | 下拉选择 |
| number + min/max | 数字输入（范围校验） |
| boolean | 开关 |
| 必填标记 | 红星 + 提交前校验 |
| 操作不支持当前素材（partial_audio_policy 等） | 禁用态 + 说明 tooltip |

## 5. 错误与空状态

| 场景 | UI 表现 |
|---|---|
| timeline JSON 解析失败 | 提交按钮上方红字：`JSON 语法错误: <位置>` |
| 任务 404 | 状态卡区域提示「任务不存在，请核对 task_id」 |
| 下载 410（文件过期） | 提示「成片已过期清理，请重新渲染」 |
| 无任务查询 | 空状态插图 + 说明文案（灰字，不放插画资源时用纯文案） |

## 6. 响应式与兼容

- 阶段 1：单页适配 ≥1024px 桌面宽度；移动端仅保证查询/下载可用
- 阶段 2：面向桌面端（时间轴操作不适配触屏），最低 1280px
